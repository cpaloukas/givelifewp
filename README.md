# GiveLifeWP

GiveLifeWP: non-commercial blood donation and preparedness awareness site, WordPress® FSE block theme. Born out of the WordPress® community, made for everyone.

**Ground rules:** non-commercial, in-kind support only, never replaces hospitals, blood banks, emergency services or official donor organizations.

## What's here

- `theme/`: the GiveLifeWP block theme (theme.json, templates, styles, fonts).
- Ideas and planned work are tracked as [issues](../../issues).

## Using the theme

Copy `theme/` into `wp-content/themes/givelifewp/` and activate it. Requires WordPress 6.7+.
